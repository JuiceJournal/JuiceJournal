# Game art notice

The item and currency images in this folder are artwork from Path of Exile and
Path of Exile 2, (c) Grinding Gear Games. They are not covered by this
project's MIT license.

Juice Journal is a fan-made tool. It is not affiliated with or endorsed by
Grinding Gear Games. The images are shown only to identify in-game items next
to their values.

The PoE 2 images were taken from Grinding Gear Games' public image CDN
(`web.poecdn.com`), using the item image paths listed by poe.ninja.

The PoE 1 category images in `poe1/` (fragment, scarab, essence, fossil, map,
divination-card, gem, unique, oil, beast, delirium-orb, catalyst, omen, tattoo)
and `poe2/idol.png`, `poe2/omen.png`, `poe2/abyssal-bone.png`, `poe2/catalyst.png`,
`poe2/liquid-emotion.png` and `poe2/verisium.png` were taken from the same CDN.
Each shows one item of its category; `divination-card.png` is the inventory icon
every divination card uses.

Other item art is not bundled. The desktop app downloads it from the same CDN
the first time an item is shown and keeps a local copy (at most 64 MB) in the
`icon-cache` folder of its user data directory, so icons also appear offline
and in the in-game overlay.
